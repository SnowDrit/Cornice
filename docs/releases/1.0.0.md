### Added
- Menu bar hiding on macOS 27. Enable Accessibility for Cornice in System Settings to use it. macOS 26 keeps its existing behavior.

### Fixed
- Switching the second divider off and on preserves divider positions and avoids duplicate dividers or a brief reveal of all icons when the layout is already known.
- Hidden dividers no longer reserve their previous empty space on macOS 27.
- Pressing Command alone no longer reveals both zones. Rearranging starts with a Command-click inside the menu bar.
- The Menu Bar tab keeps the saved grouping while icons are hidden and drops icons from apps that have quit.
- Unrelated settings changes no longer re-register unchanged keyboard shortcuts.
- Opening the always hidden zone resets the automatic hiding countdown.

### Changed
- Faster repeated hiding and revealing, with fewer menu bar scans and less work on pointer movement.
- More cautious handling of icon positions across multiple displays. Icons stay visible when their group cannot be determined reliably.

Some bugs may remain, especially on macOS 27. If you notice unexpected behavior,
please [report it in Issues](https://github.com/SnowDrit/Cornice/issues) with your
macOS version and the steps to reproduce it. See the [macOS 27 notes](https://github.com/SnowDrit/Cornice#macos-27)
for current visibility limitations.

**Install:** download `Cornice.dmg` below, drag it onto Applications.
The build is ad-hoc signed and not notarised. If macOS blocks the first launch,
follow [Apple's instructions](https://support.apple.com/en-us/102445) to approve
Cornice in System Settings > Privacy & Security after trying to open it.

Requires macOS 26 (Tahoe) or later, Apple Silicon.
